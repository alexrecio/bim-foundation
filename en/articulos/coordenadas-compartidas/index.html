      Geodesy

      The Earth is not a sphere.

      Calculations use an ellipsoid, a mathematical shape. Sea level, the geoid, is irregular.

      Three shapes for the same Earth
      Flattening 1/298 GRS80 ellipsoid
      Semi-major axis (a) 6 378km GRS80 · 6 378 137 m
      Datum Ellipsoid tied to the real Earth example: ETRS89
      Reference systems

      One point, four ways to write it.

      A reference system states which type of coordinates is used and on which datum. Without it, the numbers mean nothing.

      Geographic φ · λ · h degrees
      Geocentric X · Y · Z from the centre
      Projected E · N (+ H) metres on a plane
      Local x · y · z site origin
      Coordinate reference system
      Datum+Coordinate type+Heights=One EPSG code

      Floating point

      Far from the origin, everything jitters.

      With large numbers, any program loses precision. That is why you do not model directly in UTM.

      Why it happens

      There are not enough digits for everything.

      A floating-point number has a limited number of digits. If the integer part uses them up, none are left for decimals.

      Single precision: about 7 useful digits
      Smallest step at 4 474 km 0.5m single precision
      Smallest step at 310 m 0.03mm single precision
      The cost

      More digits, more bytes.

      Double precision doubles the size of each coordinate. In a model it barely shows; in a point cloud, it does.

      Single · float32 4bytes
      ≈ 7 digits
      Double · float64 8bytes
      ≈ 15–16 digits
      Point cloud of one billion points (X, Y, Z only)
      f6424 GB · lossless
      f3212 GB · loses 0.5 m
      LAS12 GB · to the millimetre

      Subtract the large, keep the small.

      The offset is stored only once. Each vertex carries only the small part and makes use of all its decimals.

      Quality control

      Four questions per model.

      A model can look perfect and be a hundred metres off. Before you federate it, it must answer where it is, which way it faces, at what elevation and in which system.

      01 · Where Easting and Northing of the control point
      02 · Which way Rotation to north grid, not true north
      03 · What elevation Orthometric height above sea level
      04 · Which system 25830 an EPSG code, not a name
      The options

      Five ways to check.

      Some look at the native model and others at the IFC; some are configured and others are scripted.

      IDS

      The requirement, in one file.

      A buildingSMART XML file states what the IFC must contain. It goes with the contract and any checker reads it the same way.

      IfcOpenShell

      Checking with code.

      An open-source Python library runs the IDS and also does the maths the IDS cannot: it takes the check point to UTM and compares it with the surveyor’s value.
